# Python Engineering: Language Core to FastAPI

An intensive, notebook-based course that takes an experienced JavaScript developer from the Python
language itself, through CPython internals, professional tooling, concurrency and performance, to
building and deploying production APIs with FastAPI. Every unit pairs theory with runnable code and
an "under the hood" look at how CPython implements it.

- **Target platform:** CPython 3.15, managed with [uv](https://docs.astral.sh/uv/).
- **Prerequisites:** working knowledge of JavaScript/TypeScript (variables, functions, objects,
  async code, HTTP basics).
- **Full outline:** see [SYLLABUS.md](SYLLABUS.md) for every phase, unit and section.

## Setup

1. **Install uv** (macOS/Linux; see the [uv docs](https://docs.astral.sh/uv/getting-started/installation/)
   for Windows):

   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

2. **Install Python 3.15 and the dependencies.** `uv sync` reads `.python-version`, downloads the
   interpreter if needed, creates `.venv/` and installs exactly what `uv.lock` lists:

   ```bash
   uv python install 3.15
   uv sync
   ```

3. **Register the Jupyter kernel** (once per machine):

   ```bash
   uv run python -m ipykernel install --user --name python-course --display-name "Python 3.15 (course)"
   ```

4. **Open a notebook.**
   - **VS Code:** install the recommended extensions when prompted (Python, Jupyter, Ruff), open a
     notebook from `notebooks/`, click *Select Kernel* and choose **Python 3.15 (course)**.
   - **JupyterLab:** run `uv run jupyter lab` and pick the same kernel.

Never install packages with `pip` or `%pip`; use `uv add <package>` (or `uv add --dev <package>`)
so `pyproject.toml` and `uv.lock` stay the single record of the environment.

## Rebuilding a notebook

Notebooks are generated by Python build scripts, not edited by hand. To rebuild and verify a phase
(Phase 0 shown):

```bash
uv run python scripts/phase0/build.py
uv run ruff format notebooks scripts exercises
uv run ruff check notebooks scripts exercises
uv run jupyter nbconvert --to notebook --execute --inplace \
    --ExecutePreprocessor.kernel_name=python-course notebooks/phase0_environment_setup.ipynb
uv run python exercises/solutions/phase0_solutions.py
```
